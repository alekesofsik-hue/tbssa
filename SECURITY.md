# Безопасность

## Отчёты об уязвимостях

Если вы нашли уязвимость, пожалуйста, не создавайте публичный issue. Напишите владельцу репозитория напрямую (например, через приватное сообщение на GitHub).

## Рекомендации при развёртывании

- Храните секреты только в `.env`; после создания задайте `chmod 600 .env`.
- Не храните в коде, документации и публичных конфигурациях `TELEGRAM_BOT_TOKEN`, `MAX_BOT_TOKEN`, `DB_URL` и приватные SSH-ключи.
- Используйте `ADMIN_IDS` и `MAX_ADMIN_IDS` только для первичного bootstrap. После запуска проекта основным источником прав доступа становится база данных.
- Проверка SSH host key обязательна: добавьте host key в `known_hosts` или используйте `SSH_HOST_KEY_FINGERPRINT`.
- Права на файл базы данных и рабочую директорию сервиса должны быть ограничены пользователем, под которым запускается бот.
- Если вы используете root-level `tbssa.service`, проверьте, что в нём нет лишних host-specific путей и секретов перед публикацией или переносом.
