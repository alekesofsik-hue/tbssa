## Правила прохождения

- Используйте временные тестовые сущности для CRUD-проверок.
- Не удаляйте и не отключайте production-серверы и production-аккаунты.
- Для проверки broadcast и межплатформенных уведомлений заранее подготовьте минимум двух администраторов.
- После завершения тестов верните изменённые настройки в исходное состояние.

- [ ] Сервис `tbssa` запущен и отвечает в Telegram.

- [ ] В логах есть запись об активной MAX webhook-подписке.
- [ ] Подготовлен временный тестовый сервер для CRUD-проверок.
